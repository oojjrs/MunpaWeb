프로젝트별 작업 규칙

  • 사용자가 명시적으로 선택하기 전까지 서버, 백엔드, 패키지 매니저, 빌드 시스템을 추가하지 않는다.
  • GitHub Pages에서 직접 동작해야 하므로 상대 경로, 정적 자산 경로, 서비스워커 scope를 변경할 때 실제 배포 경로를 함께 본다.
  • 서비스워커나 오프라인 캐시는 파일 직접 열기로 판단하지 않는다. localhost, 127.0.0.1, 또는 HTTPS에서 확인한다.
  • 앱 셸 캐시를 바꾸면 src/app.js의 APP_VERSION과 sw.js의 CACHE_NAME을 함께 맞춘다.
  • PowerShell 출력의 한글 깨짐은 파일 손상으로 단정하지 말고 rg 또는 명시적 UTF-8 읽기로 다시 확인한다.
  • 현대화 무협 배경과 캐릭터 아트 기준은 Design.html의 아트 방향 섹션을 기준으로 한다.
