# MunpaWeb

A browser-only game project published with GitHub Pages.

## Local Preview

Open `index.html` directly in a browser for a quick check.

Service worker caching only activates on `localhost`, `127.0.0.1`, or HTTPS, so offline behavior is verified after running from GitHub Pages or a local static server.

## Deployment

Pushes to `main` deploy through GitHub Actions to GitHub Pages.
